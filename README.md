# Resume Demo｜莊哲昀 AJ 講師簡歷

以 A4 直式紙本履歷與螢幕閱讀為目的的講師介紹頁面示範。

## 檔案

- `lecturer-profile-concept-01.html`：高彩度、創意工具感的 A4 紙本版
- `lecturer-profile-concept-02.html`：理性編輯式的 A4 紙本版
- `lecturer-profile-concept-02-responsive.html`：適用於筆電、平板與手機的 RWD 版本
- `output/pdf/`：兩款 A4 紙本版的 PDF 匯出檔

所有文案內容依提供的講師簡歷整理；SVG 視覺素材置於 `assets/`。

## 瀏覽

直接以瀏覽器開啟任一 HTML 檔即可。RWD 版本建議使用 `lecturer-profile-concept-02-responsive.html`。
